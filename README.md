# Audio Forensics: War Intercept

This repository contains tools and scripts for performing audio forensics on a recorded transmission. The project involves cleaning noisy audio, analyzing its frequencies, generating forensic visualizations, and utilizing automatic speech recognition (ASR) to transcribe the intercepted message.

## Overview of Files

* **`war-intercept.wav`**: The original intercepted audio file containing noise.
* **`warinterceptCleaned.wav`**: The denoised version of the audio file.
* **`audiocleaning.py`**: A Python script designed to filter and clean the original noisy audio.
* **`forensics.py`**: A script that performs frequency analysis and generates visual forensic artifacts, including:
  * `02fig1_fft.png` (Fast Fourier Transform plot)
  * `02fig2_spectrogram.png` (Spectrogram representation)
  * `02fig3_3D_FFT.png` (3D FFT visualization)
* **`transcription.py`**: A script that utilizes OpenAI's Whisper model to transcribe the spoken content from the cleaned audio file.
* **`03transcript.txt`**: The resulting text transcription generated by the transcription script.
* **`generate_report.py`**: A script to compile the findings and visualizations into a report.
* **`Challenge3_Submission_Report.docx`**: The finalized submission report containing the forensic analysis and transcription results.

## Requirements

The Python dependencies required to run the scripts are listed in `requirements.txt`. These primarily include scientific computing, audio processing libraries, and `openai-whisper`.
You can install them via:
```bash
pip install -r requirements.txt
```

## Workflow

1. **Audio Cleaning**: Run `audiocleaning.py` to denoise `war-intercept.wav` into `warinterceptCleaned.wav`.
2. **Transcription**: Run `transcription.py` on the cleaned audio to generate the transcript (`03transcript.txt`).
3. **Forensic Analysis**: Run `forensics.py` to extract spectrograms and FFT visualizations from the audio.
4. **Reporting**: Use `generate_report.py` to compile the visual and textual data into a final report document.
